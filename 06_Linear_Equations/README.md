# 1.4 Persamaan Linear (Linear Equations)

## Apa itu Persamaan Linear? / What Is a Linear Equation?

**Bahasa Indonesia:**
Persamaan linear adalah persamaan matematika di mana setiap suku variabelnya memiliki pangkat tertinggi 1. Persamaan ini membentuk garis lurus ketika digambarkan pada bidang koordinat.

**English:**
A linear equation is a mathematical equation where each variable term has a degree of exactly 1. When graphed on a coordinate plane, it forms a straight line.

Bentuk umum / General form:
- Satu variabel: **ax + b = c**
- Dua variabel: **ax + by = c**

## Konsep Kunci / Key Concepts

| Konsep | Deskripsi |
|--------|-----------|
| **Persamaan** | Pernyataan bahwa dua ekspresi bernilai sama (=) |
| **Solusi** | Nilai variabel yang membuat persamaan benar |
| **Sifat kesetaraan** | Operasi yang sama pada kedua ruas mempertahankan kesetaraan |
| **Kontradiksi** | Persamaan tanpa solusi (misal: 3 = 5) |
| **Identitas** | Persamaan yang selalu benar (solusi tak hingga) |

## Ringkasan / Summary

Persamaan linear adalah jenis persamaan yang paling mendasar dan memiliki aplikasi luas dalam kehidupan sehari-hari, sains, ekonomi, dan teknik. Kemampuan menyelesaikan persamaan linear adalah dasar untuk mempelajari sistem persamaan, pertidaksamaan, dan kalkulus.

Linear equations are the most fundamental type of equations with wide applications in daily life, science, economics, and engineering.
