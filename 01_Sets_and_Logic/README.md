# 1.14 Sets and Logic / Himpunan dan Logika

## Overview / Gambaran Umum

Set theory and logic are the foundations of all mathematics. Sets define
collections; logic defines reasoning. Together they form the bedrock on
which proofs, algorithms, and mathematical structures are built.

## What You Will Learn / Yang Akan Dipelajari

- **Himpunan (Sets):** definition, notation, types, operations
- **Operasi Himpunan (Set Operations):** union, intersection, difference, complement
- **Cartesian Product and Power Set**
- **Kardinalitas (Cardinality):** finite, countably infinite, uncountable
- **Proposisi dan Nilai Kebenaran (Propositions):** true/false statements
- **Konektif Logika (Logical Connectives):** AND, OR, NOT, XOR, implications
- **Tabel Kebenaran (Truth Tables)**
- **Hukum De Morgan (De Morgan's Laws)**
- **Proof Techniques:** direct, contradiction, contrapositive, induction

## Quick Reference / Referensi Cepat

### Set Operations
- **Union:** A ∪ B = {x : x ∈ A or x ∈ B}
- **Intersection:** A ∩ B = {x : x ∈ A and x ∈ B}
- **Difference:** A - B = {x : x ∈ A and x ∉ B}
- **Complement:** A'= {x ∈ U : x ∉ A}

### De Morgan's Laws
- (A ∪ B)'= A'∩ B'
- (A ∩ B)'= A'∪ B'

### Logic
- p → q is FALSE only when p=T and q=F
- Contrapositive of p→q is ¬q→¬p (logically equivalent)

## Summary / Ringkasan

Sets and logic are the DNA of mathematics. Every theorem, proof, and
algorithm ultimately rests on these foundations. Understanding them
unlocks rigorous mathematical thinking across all disciplines.
