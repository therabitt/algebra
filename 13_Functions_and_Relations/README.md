# 1.8 Fungsi dan Relasi (Functions and Relations)

## Gambaran Umum

Fungsi adalah konsep paling fundamental dalam matematika modern.
Hampir semua cabang matematika menggunakan fungsi.

## Yang Akan Dipelajari
- Relasi vs fungsi, uji garis vertikal
- Domain, kodomain, range
- Fungsi injektif, surjektif, bijektif
- Komposisi fungsi
- Fungsi invers
- Fungsi genap/ganjil
- Transformasi fungsi
- Fungsi pecahan (piecewise)
