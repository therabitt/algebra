# 1.19 Teorema Binomial (Binomial Theorem)

## Gambaran Umum

Teorema Binomial memberikan ekspansi eksplisit dari (a+b)ⁿ untuk sembarang n bilangan bulat positif.
Muncul di: probabilitas (distribusi binomial), kombinatorik, aproksimasi numerik, dan kalkulus.

## Yang Akan Dipelajari
- Segitiga Pascal dan polanya
- Koefisien binomial C(n,k) = n!/(k!(n-k)!)
- Teorema Binomial: (a+b)ⁿ = Σ C(n,k) aᵏ bⁿ⁻ᵏ
- Suku umum (general term) dan suku tengah
- Identitas binomial
- Aproksimasi binomial untuk (1+x)ⁿ ketika x kecil
