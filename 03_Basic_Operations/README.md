# 📚 Algebra 1.2: Operasi Dasar dan Sifat-Sifatnya
# Basic Operations and Their Properties

## 🇮🇩 Deskripsi | 🇬🇧 Description

**ID:** Modul ini membahas empat operasi aritmatika dasar beserta sifat-sifatnya secara mendalam, termasuk operasi lanjutan seperti modulo, perpangkatan, dan akar. Memahami sifat-sifat ini adalah fondasi utama aljabar dan matematika modern.

**EN:** This module covers the four fundamental arithmetic operations and their properties in depth, including extended operations like modulo, exponentiation, and root extraction. Understanding these properties is the primary foundation of algebra and modern mathematics.

---

## 🎯 Tujuan Pembelajaran | Learning Objectives

Setelah mempelajari modul ini, kamu akan dapat / After studying this module, you will be able to:

- ✅ Mendefinisikan dan melakukan keempat operasi dasar (+, −, ×, ÷) / Define and perform all four basic operations
- ✅ Membuktikan sifat komutatif, asosiatif, dan distributif / Prove commutative, associative, and distributive properties
- ✅ Memahami mengapa pembagian dengan nol tidak terdefinisi / Understand why division by zero is undefined
- ✅ Menggunakan aturan urutan operasi (PEMDAS/BODMAS) / Apply order of operations rules
- ✅ Menghitung modulo dan pembagian bulat / Compute modulo and integer division
- ✅ Menerapkan hukum-hukum perpangkatan / Apply laws of exponentiation
- ✅ Menghitung FPB dan KPK / Compute GCD and LCM
- ✅ Memfaktorkan bilangan ke faktor prima / Factor numbers into prime factors
- ✅ Memahami aksioma field sebagai struktur aljabar formal / Understand field axioms as formal algebraic structure
