# 1.17 Pertidaksamaan Kuadrat & Rasional

## Gambaran Umum

Berbeda dari 1.5 (pertidaksamaan linear), topik ini menangani:
- **Pertidaksamaan kuadrat:** ax² + bx + c > 0
- **Pertidaksamaan rasional:** P(x)/Q(x) > 0
- **Pertidaksamaan nilai mutlak lanjut:** |f(x)| > g(x)

Kunci: **analisis tanda** di setiap interval.

## Yang Akan Dipelajari
- Metode interval / Sign chart (tabel tanda)
- Pengaruh multiplisitas akar terhadap tanda
- Pertidaksamaan rasional: perhatikan Q(x)!
- Pertidaksamaan dengan nilai mutlak bersarang
- Aplikasi: domain fungsi, ketidaksamaan fisika
