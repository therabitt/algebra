# 1.17 Pertidaksamaan Kuadrat & Rasional — Teori Lengkap

## 1. Pertidaksamaan Kuadrat
Bentuk: ax² + bx + c {>, ≥, <, ≤} 0

### Langkah Penyelesaian:
1. Jadikan ruas kanan = 0
2. Faktorkan sisi kiri
3. Temukan titik kritis (akar-akar)
4. Buat tabel tanda (sign chart)
5. Tentukan interval yang memenuhi

### Pengaruh Diskriminan:
- D > 0: dua akar real, tiga interval
- D = 0: satu akar (double), dua interval
- D < 0 dan a > 0: selalu positif (tidak ada solusi untuk < 0)
- D < 0 dan a < 0: selalu negatif (tidak ada solusi untuk > 0)

### Pengaruh Multiplisitas:
- Akar tunggal: tanda BERGANTI di titik ini
- Akar ganda: tanda TIDAK BERGANTI (menyentuh sumbu, tidak memotong)

## 2. Pertidaksamaan Rasional
Bentuk: P(x)/Q(x) {>, ≥, <, ≤} 0

### PENTING: Jangan kalikan dengan Q(x) langsung!
(Q bisa positif atau negatif tergantung x — tanda bisa balik)

### Langkah Penyelesaian:
1. Jadikan ruas kanan = 0
2. Faktorkan P dan Q
3. Titik kritis = akar P DAN akar Q
4. Tabel tanda (hati-hati: akar Q dikecualikan dari solusi!)
5. Tentukan interval yang memenuhi

## 3. Sign Chart (Tabel Tanda)
Teknik universal:
1. Temukan semua titik kritis (akar numerator & denominator)
2. Urutkan pada garis bilangan
3. Pilih titik uji di setiap interval
4. Hitung tanda ekspresi di titik uji
5. Gunakan alternating sign jika faktor tidak berulang

## 4. Pertidaksamaan |f(x)| > g(x)
Kasus bergantung pada tanda g(x):
- g(x) < 0: selalu terpenuhi (|f(x)| ≥ 0 > g(x))
- g(x) ≥ 0: ekuivalen dengan f(x) > g(x) ATAU f(x) < -g(x)

|f(x)| < g(x) dengan g(x) > 0: ekuivalen dengan -g(x) < f(x) < g(x)

## 5. Pertidaksamaan dengan Persamaan Nilai Mutlak Bersarang
|f(x)| > |g(x)|  ⟺  f(x)² > g(x)²  ⟺  (f(x)-g(x))(f(x)+g(x)) > 0
