# 1.18 Bilangan Kompleks (Complex Numbers)

## Gambaran Umum

Bilangan kompleks memperluas bilangan real dengan mendefinisikan i = √(-1).
Ini "melengkapi" bilangan real agar SETIAP polinomial punya akar (Teorema Fundamental Aljabar).

**Aplikasi:** Fisika kuantum, teknik elektro (impedansi AC), pemrosesan sinyal (FFT), fraktal (himpunan Mandelbrot).

## Yang Akan Dipelajari

| Topik | Deskripsi |
|-------|-----------|
| Bentuk aljabar | a + bi, operasi dasar |
| Konjugat dan modulus | z̄ = a-bi, |z| = √(a²+b²) |
| Bentuk polar | r·e^(iθ) = r(cos θ + i sin θ) |
| Formula De Moivre | (r·e^(iθ))^n = rⁿ·e^(inθ) |
| Akar dari bilangan kompleks | n-th roots |
| Himpunan Mandelbrot (preview) | iterasi z→z²+c |
