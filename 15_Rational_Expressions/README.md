# 1.16 Pecahan Aljabar (Rational Expressions)

## Gambaran Umum

Ekspresi rasional (pecahan aljabar) adalah pecahan di mana pembilang dan/atau penyebut adalah polinomial.
Ini adalah generalisasi langsung dari pecahan bilangan ke dunia aljabar.

**Contoh:** (x²-1)/(x+2),  (3x+5)/(x²-4),  (2x²-5x+3)/(x-1)

## Yang Akan Dipelajari

| Sub-topik | Deskripsi |
|-----------|-----------|
| Domain | Nilai x yang membuat penyebut ≠ 0 |
| Simplifikasi | Membagi pembilang & penyebut dengan faktor sekutu |
| Penjumlahan/Pengurangan | Menyamakan penyebut (KPK polinomial) |
| Perkalian | Kalikan langsung, sederhanakan |
| Pembagian | Kali dengan resiprokal |
| Persamaan rasional | Selesaikan, verifikasi tidak ada solusi extraneous |
| Dekomposisi parsial | Pecahkan menjadi pecahan-pecahan sederhana |
