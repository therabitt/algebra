# 1.10 Faktorisasi — Teori Lengkap

## 1. Faktor Persekutuan Terbesar (GCF/FPB)
Langkah pertama faktorisasi: cari GCF semua suku.
Contoh: 6x^2 + 9x = 3x(2x + 3)

## 2. Pola Khusus
| Pola | Faktorisasi |
|------|-------------|
| a^2 - b^2 | (a+b)(a-b) |
| a^2 + 2ab + b^2 | (a+b)^2 |
| a^2 - 2ab + b^2 | (a-b)^2 |
| a^3 + b^3 | (a+b)(a^2-ab+b^2) |
| a^3 - b^3 | (a-b)(a^2+ab+b^2) |

## 3. Pemfaktoran Trinomial ax^2 + bx + c
Metode AC: cari dua bilangan m,n sehingga m*n=ac dan m+n=b.
Contoh: 6x^2 + 7x + 2, ac=12, m+n=7 -> m=3,n=4
-> 6x^2 + 3x + 4x + 2 = 3x(2x+1) + 2(2x+1) = (3x+2)(2x+1)

## 4. Faktorisasi dengan Pengelompokan (Grouping)
ax + ay + bx + by = a(x+y) + b(x+y) = (a+b)(x+y)

## 5. Faktor tak tereduksi (Irreducible)
Atas Q: x^2 + 1 tidak bisa difaktorkan
Atas C: x^2 + 1 = (x+i)(x-i)

## 6. Teorema Faktorisasi Unik
Setiap polinomial bisa difaktorkan secara unik atas C (Fundamental Theorem of Algebra).
