# 1.10 Faktorisasi (Factorization)

Faktorisasi adalah proses mengurai ekspresi aljabar menjadi perkalian faktor-faktornya.
Berguna untuk menyederhanakan, mencari akar, dan menyelesaikan persamaan.

## Topik
- GCF, pengelompokan, pola khusus (a²-b², a²+2ab+b², kubus)
- Trinomial: metode AC dan trial-and-error
- Faktorisasi atas Q, R, dan C
